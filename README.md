# OpenAPI Mock Server Generator

## Requirements Engineering & UML Use-Case Modelling

### Problem Statement

A developer productivity tool that ingests OpenAPI 3.0 YAML/JSON specifications, creates dynamic mock REST endpoints with schema validation, and simulates configurable response latency.

### Actors

- API Developer
- QA Engineer

## Functional Requirements

- FR-001: OpenAPI Specification Parsing
- FR-002: Mock Endpoint Generation
- FR-003: Schema-Compliant Response Generation
- FR-004: Configurable Response Latency
- FR-005: API Request Validation

## Non-Functional Requirements

- NFR-001: Performance
- NFR-002: Security & Reliability
